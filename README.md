## Mob Trinkets

Mob Trinkets adds **12 charms** themed after vanilla mobs. Each one gives a passive bonus while equipped and has two active skills that unlock as you use it

***

### How it works

1.  **Collect Dusty Fragments.** Breaking natural stone (stone, deepslate, granite, diorite, andesite) has a 5% chance to drop one.
2.  **Build an Assembler** and feed it fragments.
3.  **Unlock a slot.** You start with no trinket slots. Trinket Sigils turn up in structure chests, and using one unlocks a slot for 10, 20, then 30 experience levels. Three slots max.
4.  **Equip trinkets** from the button on your inventory screen.
5.  **Kill things.** Hostile mobs give mastery points to every equipped trinket. Killing the mob a trinket is based on gives triple.

| Tier |Mastery points |Unlocks                    |
| ---- |-------------- |-------------------------- |
| I    |0              |Passive bonus              |
| II   |40             |Passive x1.5, first skill  |
| III  |150            |Passive x2.0, second skill |

All thresholds and multipliers are configurable.

***

### The Assembler

This is the only way to get trinkets, and it's a gamble. Put a Dusty Fragment in, wait five seconds, and see what comes out.

| Roll |What you get                                              |
| ---- |--------------------------------------------------------- |
| 50%  |Junk: flint, coal, cobblestone, gravel, andesite, diorite |
| 30%  |Raw iron, raw copper, redstone, lapis, quartz             |
| 15%  |Diamond, emerald, raw gold, amethyst shard                |
| 4%   |Echo shard or ancient debris                              |
| 1%   |A random Mob Trinket                                      |

You will lose this gamble most of the time. That's the deal.

It works with hoppers: insert from the top or sides, extract from the bottom.

### Skills

The first skill needs Tier II, the second needs Tier III. Every skill has a cooldown.

| Trinket             |Tier II        |Tier III         |
| ------------------- |-------------- |---------------- |
| Bee Wing            |Pollen Dash    |Honey Shield     |
| Skeleton Bone Charm |Bone Armor     |Rattle           |
| Goat Horn Charm     |Ram Charge     |Horn Blast       |
| Drowned Pearl       |Tidal Surge    |Riptide Burst    |
| Slime Heart         |Slime Bounce   |Slime Wave       |
| Phantom Wing        |Glide          |Haunt            |
| Guardian Eye        |Prismatic Beam |Guardian's Ward  |
| Creeper Heart       |Volatile Burst |Chain Detonation |
| Blaze Core          |Flame Lash     |Inferno Ring     |
| Spider Fang         |Venom Strike   |Silk Snare       |
| Magma Core          |Magma Shield   |Eruption         |
| Ender Eye           |Void Pull      |Phase Shift      |

The explosion skills don't break blocks, so your base is safe. Prismatic Beam works differently from the rest: hold the key to charge, keep holding to fire, release to stop.

#### Controls

*   **R / G / V**: use the skill in trinket slot 1 / 2 / 3
*   **Shift + R / G / V**: use that trinket's second skill
*   **K**: move and resize the trinket HUD

All keys can be rebound under Mob Trinkets in Controls.

***

### Trinket Sigils

Sigils unlock your trinket slots. They have a 15% chance (configurable) to appear in these structure chests: ancient cities, strongholds, woodland mansions, bastions, end cities, buried treasure, desert pyramids, jungle temples, dungeons, abandoned mineshafts and trial chamber rewards.

***

### Commands

*   `/trinketmastery max`: maxes mastery on your equipped trinkets
*   `/trinketcooldown <on|off> <players>`: toggles skill cooldowns for the targets
